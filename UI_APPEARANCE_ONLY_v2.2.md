# ORYN UI Edition v2.2

This release changes appearance only.

Runtime logic was not edited. Compared with UI Edition v2.1, the only runtime
source file changed is `frontend/src/index.css`.

Visual changes:
- floating instrument-style bottom navigation dock
- angular 7–12 px geometry instead of pill-heavy controls
- larger/heavier icon treatment
- dark graphite/gold Studio Kinematics visual language
- technical cards with sharper corners and stronger borders
- rectangular hardware-key buttons
- console-style input/select fields
- redesigned hover/active states
- stronger page-title hierarchy
- new scrollbar/status/slider treatment
- distinct mobile dock treatment
- redesigned light mode

No HOME, motion, calibration, controller, terminal, clearing, pattern, playlist,
API, Python, TypeScript/TSX function, configuration, or machine logic was edited.
