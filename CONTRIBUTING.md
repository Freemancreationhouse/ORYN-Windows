# Contributing to ORYN

ORYN is maintained as a Studio Kinematics kinetic-table control project.

For this UI Edition, changes to motion, homing, calibration, controller streaming, clearing, or Theta–Rho mathematics should be treated separately from visual changes. UI work should remain isolated from the working machine-control core wherever possible.

Before submitting changes, run the available backend tests and frontend checks for the part of the project you modified. Hardware-dependent tests should only be run with a safe test setup.

Licensing requirements are defined in the repository license files. Required third-party and pattern attribution must be preserved.
